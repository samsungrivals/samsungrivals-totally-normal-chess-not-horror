# samsungrivals-totally-normal-chess-not-horror

and that's true — a normal chess app but becomes not normal.

A single-file HTML chess game with a full meta-game on top: skin rolls, board/piece skins, ELO matchmaking, AI opponents (including Magnus, Hikaru, Bobby, Garry, Fabi), friends, a shop with godly packs, music, and admin commands.

## Rules

- Don't use an auto clicker — will ban permanent.
- Report bugs.

## Run locally

Just open `index.html` in a browser — no build step needed.

## Deploy

`package.json` is set up so Railway / any Node host runs `serve` on `$PORT`.

```bash
npm install
npm start
```
